## Running the App

### On brainlife.io

Open the App at [doi.org/10.25663/bl.app.12](https://doi.org/10.25663/bl.app.12), choose `neuro/wmc-deprecated` from your project and press **Execute**. The results are saved to your project as `neuro/tractmeasures`.

### Locally

You need [Singularity/Apptainer](https://apptainer.org/) (the App runs in `brainlife/mcr:neurodebian1604-r2017a`), [`jq`](https://jqlang.github.io/jq/).

1. Clone this repository.
2. Create `config.json` with the paths to your inputs and the parameters:

   ```json
   {
       "afq_fg": "/path/to/AFQ/afq_fg"
   }
   ```

3. Run `./main`.
